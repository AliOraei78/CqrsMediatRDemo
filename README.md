## Technologies

* .NET 8
* ASP.NET Core Web API
* MediatR 14.0.0
* Entity Framework Core
* Clean Architecture

## Project Structure

* CleanCQRSDemo.Domain
* CleanCQRSDemo.Application
* CleanCQRSDemo.Infrastructure
* CleanCQRSDemo.Api
